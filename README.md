# Dokr
MacOS Dock Utility that can change various hidden settings in the dock and normal ones.

## Xattr Command:
If the app does not open since the app is unsigned, type:
```zsh
xattr -cr 
```
with a leading space then drop the app into the terminal window (zsh)                                                                          
If you get the “cannot verify developer” bullshit, you can just right-click the app → Open → Open.
